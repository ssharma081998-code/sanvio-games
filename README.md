# SANVIO GAMES

A responsive, free-to-play browser gaming platform. This repository contains the initial homepage and launch-catalog UI for ten original games.

## Current status

- [x] Responsive landing page
- [x] Ten-game launch catalog
- [x] Category filters and live search
- [x] Mobile-friendly layout
- [ ] Individual playable game implementations
- [ ] Score persistence and game testing

## Tech stack

HTML5, CSS3, vanilla JavaScript and GitHub Pages-compatible static files.

## Run locally

Open `index.html` in a modern browser or use any local static server.

## Deploy with GitHub Pages

1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait for the deployment workflow to finish.

A custom domain can be configured later in GitHub Pages settings. Configure the DNS records with your domain provider and confirm HTTPS before sharing the site.
