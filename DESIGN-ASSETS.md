## Add the image files

1. Download and extract `sanvio-games-visual-assets.zip`.
2. Open the repository on GitHub and open the `assets` folder.
3. Upload all 18 `.webp` files from the extracted `assets` folder. Keep the filenames unchanged.
4. Once uploaded, the homepage can safely be switched to the new visual design.

The images are design artwork, not playable game screenshots. Game cards and game pages should still use real, working gameplay.
